# Netflix Clone Tu Nguyen

## Overview

- This project is a personal clone of Netflix built with React.js and uses The Movie Database (TMDb) API to fetch movie and TV data. It is created purely for learning and frontend practice—to improve skills in API integration, component design, and responsive UI.

**🗓️ Project created on:** November 29, 2022

## Technologies & Libraries:

- **ReactJS:** The core framework for building the frontend user interface.
- **Firebase:** Provides backend services like authentication, database, and hosting.
- **axios:** For making HTTP requests to fetch data from APIs.
- **react-slick:** Enables the creation of responsive and touch-friendly carousels.
- **react-youtube:** Show Video Youtube

## API Reference:

- [TMDB API](https://developer.themoviedb.org/reference/getting-started)

## Pages:

- Home Page
- Login/ Register Page
- MOVIE Page

## Main Features:

- **Authentication:** Allows users to sign up, sign in, and sign out securely.
- **Show List Movie:** Show list of movies by imdb of all genres
